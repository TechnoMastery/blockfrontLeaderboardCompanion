# BlockFront Leaderboard Companion
Check stats of BlockFront in real time !

[BlockFront modpack on Modrinth](https://modrinth.com/modpack/blockfront-mod-pack)<br>
[BlockFront mod on Modrinth](https://modrinth.com/mod/blockfront)

## API notice
Some features require an API key which is only given out to people selected by the BlockFront team.
This app allows you to add an API key, however features requiring one **have not been tested**.
If you own an API key and wish to help us test those features, fill free to contact us !
---
| Feature                               | Key required | Implemented |
|---------------------------------------|--------------|-------------|
| See online player count               | no           | no          |
| See scoreboard                        | no           | no          |
| See map stats                         | no           | no          |
| See map ratings                       | no           | no          |
| Checkout a specific player's profil   | yes          | no          |
| Checkout a spectific player's matches | yes          | no          |
| Checkout a clan's data                | yes          | no          |
| Checkout a match's data               | yes          | no          |
